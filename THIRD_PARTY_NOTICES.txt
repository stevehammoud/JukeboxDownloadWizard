Online metadata and artwork services
------------------------------------

MusicBrainz
Website: https://musicbrainz.org/
API docs: https://musicbrainz.org/doc/MusicBrainz_API
Rate limiting: https://musicbrainz.org/doc/MusicBrainz_API/Rate_Limiting
Purpose: Looks up recording title, artist credit, release title, release date,
and MusicBrainz identifiers.
Usage notes: Requests should use a meaningful User-Agent and should be cached
where possible. This app caches metadata lookups to avoid unnecessary requests.
MusicBrainz core data is CC0/public-domain style. Some supplementary data is
Creative Commons Attribution-NonCommercial-ShareAlike.

Cover Art Archive
Website/API docs: https://musicbrainz.org/doc/Cover_Art_Archive/API
Purpose: Looks up release cover art using MusicBrainz release identifiers.
Usage notes: This app caches downloaded cover artwork to avoid repeated
requests for the same release. Album covers are collected for archival access
and remain subject to the rights of the artists, labels, and other copyright
owners. Users are responsible for confirming they may reuse generated artwork
that includes cover art.

fanart.tv
Website: https://fanart.tv/
API key page: https://fanart.tv/get-an-api-key/
Purpose: Optional artist artwork source for marquee right-side artwork using
MusicBrainz artist identifiers.
Usage and policy notes:
- Public programs must inform users about fanart.tv and the images used.
- Users should be allowed to provide their own personal API key in addition to
  any project key used by the application.
- Do not use fanart.tv API methods inside another API for third-party use.
- Do not use the fanart.tv API commercially without written consent.
- Do not make more requests than necessary. Do not bulk-download their content.
- Use documented API methods only.
- Keep the email address on the fanart.tv account current so fanart.tv can
  contact the key holder if needed.

Users are responsible for following the applicable service terms and copyright
law. Download only content you own, have permission to use, or are otherwise
legally allowed to download and reuse.
