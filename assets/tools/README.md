# Third-party tools

Release packages bundle yt-dlp, FFmpeg/FFprobe, and Deno under their respective licenses. These large third-party binaries are intentionally not committed to this source repository.

Expected installer layout when packaging:

- assets/tools/yt-dlp.exe
- assets/tools/deno/deno.exe
- assets/tools/ffmpeg/bin/ffmpeg.exe
- assets/tools/ffmpeg/bin/ffprobe.exe

See THIRD_PARTY_NOTICES.txt for license and usage notes.
